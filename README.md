# PageXpress

一个基于 AutoHotkey v1 的 Windows 窗口管理工具。它通过快捷键、轮盘和可视化迷彩区域，让常用窗口可以快速呼出、预览、隐藏和调整。

## 功能

- 为窗口绑定 `Alt + 数字` 快捷键，快速显示或隐藏窗口。
- 长按快捷键时预览窗口，松开后恢复原来的显示状态。
- 使用轮盘选择窗口，扇区内显示窗口图标与绑定键角标，中心舱显示应用名和标题。
- 轮盘预览不会抢占键盘焦点，退出扇区后恢复窗口原来的层级。
- 迷彩模式提供独立的半透明矩形触发区域。
- 按住可配置的迷彩编辑抑制键，可以拖动区域或拖拽边缘调整大小。
- 鼠标停留在窗口或其控制条上时保持迷彩窗口显示。
- 同一窗口再次打开控制条时关闭控制条，鼠标离开窗口和控制条后自动关闭。
- 控制条内可调整窗口透明度、置顶状态、绑定键、迷彩触发区域尺寸和窗口宽高。
- 窗口缩放支持锁定长宽比，按比例联动另一边。

## 使用

1. 安装 [AutoHotkey v1](https://www.autohotkey.com/)。
2. 双击运行 `WindowManager.ahk`。
3. 使用配置页设置快捷键和窗口绑定。
4. 配置文件保存在脚本目录下的 `config.ini`，该文件是本机配置，不默认提交到 Git。

## 默认操作

| 操作 | 默认快捷键 |
| --- | --- |
| 窗口轮盘 | `Alt + =`（备用 `Alt + -`） |
| 当前窗口控制条 | `Alt + M` |
| 配置页 | `Ctrl + Alt + ~` |
| 迷彩编辑抑制键 | `Shift` |

具体绑定以配置页和本地 `config.ini` 为准。

## 窗口轮盘

按住轮盘快捷键（默认 `Alt + =`）打开，鼠标朝要切换的窗口方向移动，松开即切过去；松开时鼠标停在中心圆内则视为取消。

```
        ╭───────────────────────╮
        │    ②  ╭─────────╮  ③  │   环带：细带 + 直边分块（饼图式），只画这一圈
        │  ①    │  图标   │    ④  │   扇区内：窗口图标 + 绑定键角标
        │  ⑨    │ 应用名  │    ⑤  │   中心舱：圆形，显示应用名与窗口标题
        │    ⑧  │ 窗口标题│  ⑥   │   死区：中心圆内松开即取消
        ╰───────────────────────╯
             ⑦            ╰── 命中区是"方向"：朝哪边都算数，甩出环外也不丢
```

- **命中区是一整片扇形，不用瞄准**：内侧到中心舱的圆边为止，外侧不封口，角向也不留缝。
  只要朝某个方向离开中心圆就算选中 —— 不必把光标停在环上，甩过头也不会掉选中；
  扇区之间那条细缺口同样不参与判定，所以掠过边界不会闪一下"未选中"。
  以 `Size=110`（外半径按下限取到 120）为例：旧版只有 `77px ~ 120px` 那一圈算数，
  而且是按方向断开的；现在 `68px` 以外全都算数，半径 300px 之内的可命中面积约为原来的 10 倍。
- **越界带一点粘性**：已选中的扇区要多走 6° 才换、退回中心圆要多走 10px 才取消。
  这是给手抖和"正上方恰好压在分界线上"准备的 —— 少了它，光标停在边界时两个扇区
  （或者选中与未选中）会来回翻，预览窗口跟着反复升起、落下。
- **键位角标**就是 `Alt + 数字` 的绑定键，和键盘肌肉记忆对齐。
- **文字排版随环缩放**：标签框、行高、字号都由 `Size` 推导，环调小时整套等比缩小；过长的应用名/标题由 Windows 按精确宽度加省略号（`SS_ENDELLIPSIS`），不会被硬切一半，也不会折行把下一行顶出框外。
- **环太小时自动不画标签**：`LabelMode=Auto`（默认）在 `Size` 小于 170 时只保留扇区里的图标与角标 —— 读不清的字不如不显示。

### 外观配置（`config.ini` 的 `[RadialMenu]`）

| 键 | 默认 | 说明 |
| --- | --- | --- |
| `Size` | `220` | 外半径（像素） |
| `OffsetX` / `OffsetY` | `0` | 轮盘相对光标的偏移 |
| `NormalColor` / `SelectedColor` | `3A4658` / `4FC3F7` | 普通 / 选中扇区颜色 |
| `CenterColor` | `202833` | 中心舱颜色 |
| `Style` | `Band` | `Band` = 细环带（默认），`Wedge` = 旧版实心扇区 |
| `BandInnerRatio` | `0.72` | 环带内径 / 外半径 |
| `BandOuterRatio` | `0.96` | 环带外径 / 外半径 |
| `ShowIcons` | `1` | 扇区内显示窗口图标 |
| `ShowKeyBadges` | `1` | 显示绑定键角标 |
| `LabelMode` | `Auto` | 外侧标签：`Auto` 环够大才显示（`Size` ≥ 170）/ `Always` 总是显示 / `Hover` 只显示悬停项 / `Never` 不创建 |

外观键暂未放进配置页（页面高度已满），直接改 `config.ini` 后重启即可生效。

## 当前窗口控制条

对当前窗口按下 `Alt + M`，会在窗口正上方弹出一条控制条（顶部空间不足时自动翻到窗口下方）。整条按四列分组，每列两行：

```
┌──────────────────────┬─────────────┬──────────┬─────────────────────┬──┐
│ 透明度               │ 触发区域    │ 绑定     │ 窗口大小  ☑锁定比例 │ ×│
│ ▬▬▬▬●▬▬ 100%         │ [S][M][L]   │ [无   ▾] │ 宽 ▬▬●▬ 1920 px     │  │
│ ☐置顶  ☐迷彩         │  240 × 135  │ 已占用 3 │ 高 ▬▬●▬ 1080 px     │  │
└──────────────────────┴─────────────┴──────────┴─────────────────────┴──┘
```

| 分组 | 说明 |
| --- | --- |
| 透明度 | 拖动滑块调整窗口透明度（5%~100%） |
| 置顶 / 迷彩 | 复选框，勾选状态即当前状态。勾选「迷彩」后窗口最小化并显示触发区域，控制条随之关闭 |
| 触发区域 | 迷彩触发区域的三档预设尺寸：S 160×90、M 240×135、L 320×180，下方显示当前尺寸 |
| 绑定 | 为当前窗口选择 `Alt + 数字` 绑定键，下方提示已被其他窗口占用的键 |
| 窗口大小 | 宽 / 高滑块按基准尺寸的 1%~200% 缩放，右侧显示实际像素值 |
| 锁定比例 | 勾选后拖动任一滑块，另一边按当前长宽比联动 |

说明：

- 宽 / 高滑块的 100% 基准是**控制条打开那一刻**的窗口尺寸，控制条不关闭则基准不变。
- 拖过宽 / 高滑块后，这个尺寸在控制条开着期间会被"按住"：目标程序若自己改回尺寸会被拉回。
  关闭控制条即解除，窗口恢复可自由缩放（最大化 / 全屏期间也从不干预）。
- 目标窗口被移动时，控制条会跟着走，不需要重新按快捷键。
- 关闭方式有三种：再次按 `Alt + M`、点右上角 `×`、或把鼠标移出窗口与控制条范围。

## 迷彩区域编辑

启用窗口的迷彩模式后，会显示一个半透明矩形区域：

- 不按编辑抑制键时，鼠标进入区域会显示窗口，离开后自动隐藏。
- 按住编辑抑制键并拖动区域内部，可以移动区域。
- 按住编辑抑制键拖动边缘或角落，可以调整区域大小。
- 区域位置与尺寸独立于窗口保存，并被限制在屏幕范围内，不会被拖到看不见的地方。
- 窗口恢复时由系统还原到收起前的几何（`WinMinimize` / `WinRestore` 的行为），脚本不另行干预。

## 项目结构

- `WindowManager.ahk`：主程序。
- `config.ini`：本机生成的窗口绑定和快捷键配置，不纳入版本控制。

## 注意事项

- 本项目面向 Windows 和 AutoHotkey v1。
- 窗口层级恢复依赖 Windows 当前桌面状态；窗口被外部程序关闭或重排后，程序会使用仍然有效的邻近窗口作为恢复锚点。
- 要管理以管理员身份运行的窗口（例如任务管理器），本脚本也需要以管理员身份运行，否则 `WinSet` / `WinMove` 会静默失败。
- 配置页里的快捷键会在写盘前校验：空值、只有修饰键没有主键、以及互相冲突的键都会被拒绝并提示，不会写进 `config.ini`。若手工编辑 `config.ini` 写入了无效值，程序启动时会回退到该功能的默认键并弹一条 OSD 说明，不会因此打不开配置页。
- 快捷键支持 `Alt+=` 这类写法（自动转成 AHK 的 `!=`），也支持 `^!T` 这种符号写法。
