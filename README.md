# TypeReader

一个基于 AutoHotkey v1 的 Windows 窗口管理工具。它通过快捷键、轮盘和可视化迷彩区域，让常用窗口可以快速呼出、预览、隐藏和调整。

## 功能

- 为窗口绑定 `Alt + 数字` 快捷键，快速显示或隐藏窗口。
- 长按快捷键时预览窗口，松开后恢复原来的显示状态。
- 使用轮盘选择窗口，并在鼠标悬停扇区时预览对应窗口。
- 轮盘预览不会抢占键盘焦点，退出扇区后恢复窗口原来的层级。
- 迷彩模式提供独立的半透明矩形触发区域。
- 按住可配置的迷彩编辑抑制键，可以拖动区域或拖拽边缘调整大小。
- 鼠标停留在窗口或其控制条上时保持迷彩窗口显示。
- 同一窗口再次打开控制条时关闭控制条，鼠标离开窗口和控制条后自动关闭。
- 支持窗口透明度、置顶状态和绑定配置。

## 使用

1. 安装 [AutoHotkey v1](https://www.autohotkey.com/)。
2. 双击运行 `WindowManager.ahk`。
3. 使用配置页设置快捷键和窗口绑定。
4. 配置文件保存在脚本目录下的 `config.ini`，该文件是本机配置，不默认提交到 Git。

## 默认操作

| 操作 | 默认快捷键 |
| --- | --- |
| 窗口轮盘 | `Alt + Space` |
| 当前窗口控制条 | `Alt + M` |
| 配置页 | `Ctrl + Alt + ~` |
| 迷彩编辑抑制键 | `Shift` |

具体绑定以配置页和本地 `config.ini` 为准。

## 迷彩区域编辑

启用窗口的迷彩模式后，会显示一个半透明矩形区域：

- 不按编辑抑制键时，鼠标进入区域会显示窗口，离开后自动隐藏。
- 按住编辑抑制键并拖动区域内部，可以移动区域。
- 按住编辑抑制键拖动边缘或角落，可以调整区域大小。
- 窗口恢复时使用窗口原始位置，触发区域位置独立保存。

## 项目结构

- `WindowManager.ahk`：主程序。
- `config.ini`：本机生成的窗口绑定和快捷键配置，不纳入版本控制。

## 注意事项

- 本项目面向 Windows 和 AutoHotkey v1。
- 窗口层级恢复依赖 Windows 当前桌面状态；窗口被外部程序关闭或重排后，程序会使用仍然有效的邻近窗口作为恢复锚点。
